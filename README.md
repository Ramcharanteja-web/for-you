# 💖 For You - A Special Birthday Surprise for Nandhini

A personalized, interactive birthday celebration website created with love for Nandhini.

## ✨ Features
- **Interactive Entrance Gate:** 3-step teaser cards with fun dodging buttons.
- **Heartfelt Hero Section:** Floating hearts, personal birthday wishes, and photo theme.
- **Polaroid Photo Gallery:** 7 polaroid frames with zoom lightbox displaying our favorite memories.
- **Interactive Birthday Cake:** Blow out the candles to reveal a glowing flaming "18", sparklers, and sweet wishes.
- **Midnight Talks & Sisterhood Journey:** Interactive story cards and chapters of memories.
- **Wax Sealed Letter & Surprise Gift Box:** Heartfelt birthday message and confetti celebration.
- **Music Player:** Includes *Unakkenna Venum Sollu* and *Gaaju Bomma*.

## 🚀 Running Locally
Simply double-click `start.bat` or run:
```bash
python run_server.py
```
Then visit `http://localhost:5500` in your browser.
